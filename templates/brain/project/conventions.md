# Convenções e Preferências

> **TL;DR:** escolhas do usuário que valem para todo o projeto. A IA segue sem perguntar.

Só entra aqui o que o usuário confirmou. A IA pode propor um item ("quer que eu registre isso como convenção?"), mas não adiciona sozinha.

## Código

- <ex.: nomes de eventos no formato `recurso:server:acao`>

## NUI

- <ex.: tamanhos em `vh/vw`, nunca `px` fixo>

## Fluxo de trabalho

- <ex.: sempre testar no servidor local antes de pedir commit>
